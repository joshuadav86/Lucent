# Skins and themes

## What it does

- **Five skins** (shape and finish): Lucent, Retro, Glass, Neon, Studio.
- **Eight themes** (colours): Midnight, Deep Ocean, Glacier, Ultraviolet, Emerald, Ember, Graphite, Rosé. Each skin has a default theme; any theme works with any skin.
- **Classic skins:** Winamp 2 `.wsz` skins draw the player, equalizer, and queue in skin pixels, optionally at double size. "Lucent Classic" is built in. Leave classic with right-click on the player > "Lucent's own player".
- While classic, the EQ uses Winamp's 10 bands, Lucent's own buttons sit in a strip under the player, and song rows have no covers.

## Rules

- Lucent ships no third-party skins and no Winamp art, logo, or name in its branding. "Loads classic Winamp skins (.wsz)" is fine as a compatibility line. Bundle a skin only with its author's written permission or an open licence.
- "Lucent Classic" is generated by `tools/ClassicSkin/make_lucent_classic.py`; re-run it after art changes.

## Windows and Mac

Same on both. Skin and theme lists live in each app's `Themes/` and must match.

## Parity gaps

None.

## Code

- `Lucent.Core/ClassicSkins/` (loader, sprite layout, `ClassicPlayer`, `ClassicEqualizer`, `ClassicPlaylistFrame`, `ClassicSkinLibrary`)
- `Themes/SkinManager.cs`, `Themes/ThemeManager.cs`, `Windows/ClassicPlayerView.cs`, `Windows/ClassicSurfaceView.cs`, `MainWindow.Classic.cs`, `*Window.Classic.cs` in each app
- Settings: skin and theme names, `ClassicSkin` (null = Lucent's own player), `ClassicDoubleSize`, `Balance`
